FridgeWise — Mobile Application Subsystem

IoT Smart Fridge Food & Expiry Management System. Integrated Edge Hardware, Google Gemini AI Vision, and Supabase Cloud Event Ledger.

Flutter 3.47.2 / Dart 3.13.2 Supabase Cloud Gemini 1.5 Flash Vision Event-Sourced Ledger

1. System Architecture & Edge Integration

FridgeWise connects physical refrigerator hardware with cloud intelligence and a cross-platform mobile application.

Three-Tier Real-Time Pipeline:
1. Edge Hardware (Subsystem 1): ESP32-S3 CAM, Magnetic Reed Door Sensor (IN trigger), and Tactile Button (OUT trigger).
2. Cloud AI & Backend (Supabase): Image CDN Storage, Google Gemini 1.5 Flash Vision API, PostgreSQL Event Ledger, and Realtime WebSockets.
3. Mobile Application (Subsystem 2 — This Subsystem): Asynchronous Human-in-the-Loop Verification, Multi-Compartment Inventory, Freshness Tracking, and User Isolation.
